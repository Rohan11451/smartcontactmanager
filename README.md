
# [SMARTCONTACTMANAGER]

Smart Contact Manager is a full-stack web application that allows users to manage their personal contacts efficiently.
It features a responsive front-end built with HTML, CSS, and Bootstrap, and a robust back-end powered by Core Java, Spring Boot, Hibernate, and MySQL, with Maven as the build tool.

## Features

- User registration and login
- Add, view, update, and delete contacts
- Secure user authentication
- Responsive UI design with Bootstrap
- Backend logic implemented with Spring Boot and Hibernate JPA
- Persistent storage using MySQL
This project is ideal for learning full-stack Java development and demonstrates best practices in using Spring Boot for building modern web applications.
